## Stack Thesis

This is not a classic software engineering stack. It is a personal operating stack for moving from idea -> structure -> artifact -> system -> story. AI generates and structures, decks and HTML make ideas legible, owned web tools make them public, Python and APIs keep recurring systems moving, and human polish decides what is actually good.

## Category Layers

- Thinking / writing: ChatGPT
- Building / debugging: Claude Code, VS Code, Astro, GitHub
- Fast prototypes: Bolt, Lovable, Replit/Glitch-style apps
- Executive artifacts: PowerPoint, HTML/CSS slides, PDF exports
- Research: Perplexity, Deep Research, NotebookLM
- Workflow / ops: Notion-style databases, runbooks, job CRMs, calendar integration, recruiter tracking
- Adventure/product data: NPS API, OpenRouteService, geocoding, Leaflet/OpenStreetMap, AQI/wildfire/water/trail/permit data
