# Visual Direction

## Signature Pairing

Use two hero artifacts:

1. Wide desk portrait: `../../assets/saachi/photos/desk-wide.jpeg`
2. Close desk/desktop detail: `../../assets/saachi/photos/desk-close.jpeg`
3. Actual desktop screenshot: `../../assets/saachi/screenshots/desktop-full.png`
4. Actual tool screenshots from the AI stack

## Visual Read

The desk is not minimal. That is the point. It should read as a warm command center: work, applications, outdoor goals, stationery, notes, and little systems all visible at once.

## Annotated Desktop Treatment

Create an editorial annotation layer over the real photos and screenshots. The main photo should use restrained numbered newspaper-style callouts. Zoom-ins and screenshots can use cuter shapes layered on top:

- sticker labels
- speech bubbles
- starbursts
- tiny sparkles
- doodle arrows
- circles around objects
- soft sticky-note rectangles

- mountain wallpaper: "adventure brain always running"
- Outlook: "inbox as operating system"
- LinkedIn: "public-facing maze"
- OneNote/document: "loose-leaf brain"
- illustrated wall prints: "taste board"
- handwritten cards: "physical reminders"
- browser tabs: "open loops"
- webcam: "always almost on a call"
- pens/cup: "analog tools still load-bearing"

## Style

- editorial but playful
- sticker labels
- tiny desktop badges
- pale yellow sticky notes
- soft pink accents
- green from the desk/wall art
- restrained Myspace energy
- real photo + cartoon/shapes overlay
- cute annotations, not infographic seriousness

## Avoid

- making it too polished
- hiding the clutter
- generic AI visuals
- turning the profile into productivity advice
- fake desktop mockups once real screenshots exist
