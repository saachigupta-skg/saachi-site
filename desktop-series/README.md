# What's On My Desktop

This is the project folder for Saachi's `What's On My Desktop` series on `saachigupta.net/desktop`.

Use it as the slop cannon:

1. Put raw material in `00_INBOX_SLOP_CANNON`.
2. Run the prompt in `03_PROMPTS_AND_RULES/PROCESS_SLOP_CANNON.md`.
3. Move cleaned subject packages into `01_SUBJECTS`.
4. Publish finished drafts and visual specs from `02_OUTPUTS`.

The goal is to make a messy brain dump, photo dump, and desktop dump become the same consistent editorial format every time.
